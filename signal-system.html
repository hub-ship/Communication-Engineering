第一章 信号与系统基本概念

1.1 信号的分类

分类维度类型例子
连续性连续时间信号 x(t) / 离散时间信号 x[n]电压波形 / 语音采样
确定性确定信号 / 随机信号正弦波 / 噪声
周期性周期 T：x(t+T)=x(t) / 非周期市电 50Hz
能量/功率能量信号（E有限） / 功率信号（P有限）脉冲 / 周期信号

1.2 典型信号

  • 指数信号：est（s=σ+jω，一切信号分析的"原子"）
  • 正弦信号：A·sin(ωt+φ)
  • 单位冲激 δ(t)：抽样性质 ∫f(t)δ(t−t₀)dt = f(t₀)，是 LTI 系统分析的基石
  • 单位阶跃 u(t)：与 δ 的关系 δ(t)=du/dt
  • sa 函数（抽样函数）：sa(t)=sin(t)/t，理想低通滤波器的冲激响应

1.3 信号的基本运算

运算表达式注意点
翻转x(−t)以纵轴为镜
尺度x(at)a>1 时间压缩、频率展宽
时移x(t−t₀)减号右移（推迟）
微分/积分dx/dt、∫x dτ跳变处出现冲激

1.4 系统的性质

  • 线性：齐次性 + 叠加性
  • 时不变：输入延迟 → 输出同样延迟
  • 因果：输出不超前输入（物理可实现系统的必要条件）
  • 稳定：有界输入 → 有界输出（BIBO）
💡 LTI（线性时不变）系统是全课程主角：只需知道 h(t)（冲激响应），就能求任意输入的输出 —— 卷积。

第二章 LTI 系统与卷积

2.1 卷积的定义

y(t) = x(t) * h(t) = ∫−∞∞ x(τ)h(t−τ)dτ
离散：y[n] = Σk x[k]h[n−k]

2.2 卷积的性质

性质公式
交换律x*h = h*x
分配律x*(h₁+h₂) = x*h₁ + x*h₂
结合律(x*h₁)*h₂ = x*(h₁*h₂)（级联系统）
与冲激卷积x(t)*δ(t) = x(t)；x(t)*δ(t−t₀) = x(t−t₀)
微积分d/dt[x*h] = x′*h = x*h′

2.3 图解法求卷积

步骤：① 翻转 h(τ)→h(−τ) ② 平移 h(t−τ) ③ 相乘 ④ 积分(面积)
关键：确定积分上下限的交界点，分段讨论！

2.4 因果性与稳定性判据

因果 ⇔ h(t) = 0 (t<0)；稳定 ⇔ ∫|h(t)|dt < ∞（绝对可积）

2.5 卷积的工程意义

系统的零状态响应 = 输入与冲激响应的卷积。任何线性滤波、信道传输、图像模糊，本质都是卷积。FFT 加速卷积（快速卷积）是 DSP 的常用技巧。

第三章 傅里叶级数（周期信号）

3.1 三角形式

x(t) = a₀/2 + Σn=1∞[ancos(nω₁t) + bnsin(nω₁t)]
an = (2/T)∫x(t)cos(nω₁t)dt，　bn = (2/T)∫x(t)sin(nω₁t)dt

3.2 指数形式（更常用）

x(t) = Σn=−∞∞ Xnejnω₁t，　Xn = (1/T)∫T x(t)e−jnω₁tdt

3.3 典型周期信号的频谱

信号频谱特点
周期方波幅度 ∝ 1/n（奇次谐波），sa 包络
周期锯齿波幅度 ∝ 1/n（全部谐波）
周期冲激串所有谐波等幅 —— 理想抽样载波
💡 频谱三大规律：离散性（谐波间隔 ω₁）、收敛性（幅度递减）、奇偶性（实信号幅度谱偶对称、相位谱奇对称）。

第四章 傅里叶变换（非周期信号）

4.1 定义

X(jω) = ∫−∞∞ x(t)e−jωtdt　　（正变换）
x(t) = (1/2π)∫−∞∞ X(jω)ejωtdω　　（反变换）

物理意义：非周期信号可视为周期 T→∞ 的周期信号，谱线无限密集 → 连续频谱。

4.2 常见傅里叶变换对（必背！）

x(t)X(jω)
δ(t)1（全频谱均匀）
12πδ(ω)
u(t)πδ(ω) + 1/(jω)
e−atu(t), a>01/(a+jω)
矩形脉冲 gτ(t)τ·sa(ωτ/2)
sa(ωct/π)理想低通（门函数）
cos ω₀tπ[δ(ω−ω₀)+δ(ω+ω₀)]
e−at²（高斯）√(π/a)·e−ω²/4a（还是高斯）

4.3 频谱的幅度与相位

X(jω) = |X(jω)|ejφ(ω)。幅度谱决定"有什么频率成分"，相位谱决定"各成分如何对齐"—— 数字通信中相位谱同样关键。

第五章 傅里叶变换性质与应用

5.1 重要性质（考试核心）

性质时域频域
线性ax₁+bx₂aX₁+bX₂
时移x(t−t₀)X e−jωt₀（幅度不变，相位线性滞后）
频移（调制！）x(t)ejω₀tX(j(ω−ω₀))
尺度x(at)(1/|a|)X(jω/a)
时域微分dx/dtjωX
时域卷积 ⭐x*hX·H
频域卷积x·y(1/2π)X*Y
帕塞瓦尔∫|x|²dt(1/2π)∫|X|²dω（能量守恒）

5.2 时域卷积定理 —— 全书最重要的定理

✅ y(t)=x(t)*h(t) ⇔ Y(jω)=X(jω)·H(jω)。时域复杂的卷积运算变成频域简单乘法。这是 FFT 快速卷积、频域均衡、滤波器设计的理论根基。

5.3 调制与解调的频域解释

乘以 cos ωct = 频谱左右各搬移 ωc（幅度减半）—— 这就是傅里叶变换频移性质的直接应用，也是通信原理中所有调制的数学本质。

5.4 周期信号的傅里叶变换

x(t) 周期信号 → X(jω) = 2πΣ Xnδ(ω−nω₁)

把傅里叶级数系数放到冲激位置上，统一了周期与非周期信号的频谱语言。

第六章 采样定理（抽样定理）

6.1 抽样过程

抽样 = 信号 × 冲激串 → 频域：原频谱以 ωₛ 为周期进行复制搬移

6.2 奈奎斯特抽样定理

fs ≥ 2fm（信号最高频率）→ 抽样后频谱不混叠，可用低通滤波恢复原信号
  • fs = 2fm 称奈奎斯特速率
  • fs < 2fm → 混叠（aliasing）：高频成分"伪装"成低频，不可逆失真

6.3 频域抽样定理（对偶）

对时域采样：时域离散 ↔ 频域周期延拓；对频域采样：频域离散 ↔ 时域周期延拓（DFT 的理论基础）。

6.4 实际系统的抗混叠

  • ADC 前必须加抗混叠低通滤波器（因为实际信号不严格带限）
  • CD 音频 44.1 kHz：人耳上限 20 kHz × 2 + 2.05 kHz 保护带
  • 欠采样（带通抽样）在射频采样接收机中有意利用混叠 —— 带通采样定理

第七章 拉普拉斯变换

7.1 定义

X(s) = ∫0∞ x(t)e−stdt　（单边），s = σ + jω

拉氏变换 = 广义的傅氏变换（乘 e−σt 强制收敛），能处理 eatu(t) 等增长信号。

7.2 收敛域（ROC）

⚠️ 拉氏变换必须指明收敛域才唯一对应信号！这是期末考试与考研的高频陷阱。例如 1/(s−1)：ROC 为 Re(s)>1 时是 etu(t)（因果），Re(s)<1 时是 −etu(−t)（反因果）。

7.3 常用变换对与性质

x(t)X(s)ROC
δ(t)1全平面
u(t)1/sRe(s)>0
e−atu(t)1/(s+a)Re(s)>−a
t·u(t)1/s²Re(s)>0
cos ω₀t·u(t)s/(s²+ω₀²)Re(s)>0
sin ω₀t·u(t)ω₀/(s²+ω₀²)Re(s)>0

核心性质：时域卷积 → s 域乘积；时域微分 → 乘 s（初值/终值定理可快速求 f(0⁺)、f(∞)）。

7.4 用拉氏变换解微分方程

线性常系数微分方程 --拉氏变换--> s域代数方程 --求Y(s)--> 部分分式分解 --反变换--> y(t)
(自动包含初始条件，一步到位求全响应！)

第八章 Z 变换

8.1 定义

X(z) = Σn=−∞∞ x[n]z−n，z = rejω

Z 变换是离散时间信号的"拉普拉斯变换"。单位圆上 z = ejω 时退化为离散时间傅里叶变换（DTFT）。

8.2 常用 Z 变换对

x[n]X(z)ROC
δ[n]1全平面
u[n]z/(z−1)|z|>1
anu[n]z/(z−a)|z|>|a|
nanu[n]az/(z−a)²|z|>|a|
cos(ω₀n)u[n](z²−zcosω₀)/(z²−2zcosω₀+1)|z|>1

8.3 Z 反变换

  • 幂级数法（长除法）：直接展开得 x[n] 前若干项
  • 部分分式法：X(z)/z 展开后查表（最常用）
  • 留数法：x[n] = Σ Res[X(z)zn−1]

8.4 差分方程求解

# 一阶 IIR 系统: y[n] = 0.9*y[n-1] + x[n] 的单位阶跃响应
y = 0
for n in range(20):
    y = 0.9*y + 1
    print(n, round(y, 4))   # 收敛到 1/(1-0.9)=10（终值定理验证）

第九章 系统函数与稳定性

9.1 系统函数

连续：H(s) = Y(s)/X(s)；离散：H(z) = Y(z)/X(z)

零状态响应下由系统结构唯一决定，与激励无关。

9.2 极零点与系统行为

  • 极点：分母零点 → 决定响应模式（ept / an）
  • 零点：分子零点 → 决定各模式的幅度和相位
  • 极点在左半平面 → 衰减；虚轴 → 等幅振荡；右半平面 → 发散

9.3 稳定性判据

系统类型稳定条件
连续系统H(s) 全部极点位于左半 s 平面（Re<0）
离散系统H(z) 全部极点位于单位圆内（|z|<1）
劳斯判据不解方程判断特征根位置（控制理论）

9.4 频率响应的几何求解

由极零图直接画 |H(jω)|：零点靠近单位圆/虚轴 → 该频率增益出现谷；极点靠近 → 出现峰。全通系统（零极点镜像对）、最小相位系统等概念由此展开。

第十章 滤波器设计

10.1 滤波器分类

类型通带典型应用
低通 LPF|ω|<ωc抗混叠、平滑
高通 HPF|ω|>ωc隔直、边缘检测
带通 BPFω₁<|ω|<ω₂超外差接收机中频
带阻 BSF排除 ω₁~ω₂陷波去除工频干扰

10.2 理想 vs 实际滤波器

理想低通（矩形幅度特性）物理不可实现（非因果的 sa 冲激响应）。实际滤波器用通带波纹、阻带衰减、过渡带宽三大指标描述。巴特沃斯（最大平坦）、切比雪夫（等波纹）、椭圆（过渡最陡）是三大经典逼近。

10.3 数字滤波器 FIR vs IIR

FIRIIR
结构无反馈（非递归）有反馈（递归）
稳定性恒稳定需设计保证
线性相位可实现（对称冲激响应）一般不行
阶数高低（效率高）
代表窗函数法、频率抽样冲激响应不变法、双线性变换

10.4 双线性变换设计 IIR（流程）

数字指标 →(预畸变 ω=(2/T)tan(Ω/2))→ 模拟指标 → 模拟低通原型(巴特沃斯)
→ 频率变换(低通/高通/带通/带阻) → 双线性变换 s=(2/T)(1−z⁻¹)/(1+z⁻¹) → H(z)

第十一章 状态变量分析

11.1 状态方程与输出方程

连续：ẋ = Ax + Bu；y = Cx + Du　　离散：x[n+1] = Ax[n] + Bu[n]

11.2 状态方程建立

  • 由微分方程/系统函数直接实现（直接形式信号流图）
  • 由电路列写（电容电压、电感电流为状态变量）

11.3 状态方程求解

x(t) = eAtx(0) + eAt*Bu(t)（矩阵指数/状态转移矩阵 φ(t)=eAt）

11.4 可控性与可观测性

系统能控：rank[B AB … An−1B] = n；能观：rank[C; CA; …; CAn−1] = n。现代控制理论基石，也是卡尔曼滤波器的理论基础。

第十二章 习题与思考

1.（计算）已知 x(t)=e−2tu(t)，h(t)=u(t)，求 y(t)=x(t)*h(t)。

y(t) = ∫0t e−2τdτ · u(t) = (1/2)(1−e−2t)u(t)

另解（频域）：X=1/(2+jω)，H=1/(jω)+πδ(ω)，Y=XH → 部分分式得同结果。

2.（概念）为什么说 δ(t) 是 LTI 系统分析的基石？

任意信号可分解为 δ 的加权积分：x(t)=∫x(τ)δ(t−τ)dτ。由线性时不变性，响应为 x(τ)h(t−τ)的积分 —— 即卷积。所以知道了 h(t) 就知道系统对一切输入的响应，δ 是"探针"。

3.（计算）矩形脉冲宽度 τ=1ms，其频谱主瓣宽度（第一零点）是多少？

矩形脉冲频谱为 τ·sa(ωτ/2)，第一零点在 f = 1/τ = 1 kHz。脉冲越窄，频谱越宽 —— 时频对偶（尺度特性）的直接体现。

4.（判断）某系统 h[n] = 2nu[n]，是否稳定？

Σ|2n| = ∞，不绝对可和 → 不稳定。也可看极点 z=2 在单位圆外，同样结论。

5.（计算）求 y[n] = x[n] + 0.5y[n−1] 的系统函数，判断稳定性与滤波类型。

H(z) = 1/(1−0.5z−1) = z/(z−0.5)。极点 z=0.5 在单位圆内 → 稳定。|ω|=0 时 |H|=2，|ω|=π 时 |H|=2/3 → 低通。这是一阶 IIR 低通（指数平滑）滤波器。

6.（思考）说明"时域卷积 = 频域相乘"在通信系统中的三个应用。

①滤波：信号通过信道/滤波器即卷积，频域为 H(jω)加权；②快速卷积：FFT 计算长卷积，复杂度 O(N log N)，DSP 芯片核心算法；③频域均衡：OFDM 中每子载波一次复数乘法完成均衡，代替复杂时域均衡器。

7.（计算）信号 x(t)=cos(200πt)+cos(400πt)，最低抽样频率？抽样后如何恢复？

fm = 200 Hz → fs ≥ 400 Hz。恢复：截频 200<ωc<400π 的理想低通滤波器。若 fs=300 Hz，400π 分量混叠到 200π，无法恢复。

第十三章 仿真实验（Python / MATLAB）

实验一：卷积的图形验证

import numpy as np
import matplotlib.pyplot as plt

t = np.linspace(-5, 5, 1000)
x = np.exp(-2*t)*np.where(t >= 0, 1, 0)   # e^(-2t)u(t)
h = np.where(t >= 0, 1, 0)                 # u(t)

y = np.convolve(x, h) * (t[1]-t[0])        # 数值卷积(乘dt)
ty = np.linspace(2*t[0], 2*t[1], len(y))

plt.plot(ty, y); plt.title('y(t)=x(t)*h(t)')
plt.grid(); plt.show()   # 与理论 (1-e^(-2t))u(t)/2 对比

实验二：方波的傅里叶合成（吉布斯现象）

t = np.linspace(0, 4, 2000)
square = np.sign(np.sin(2*np.pi*t))         # 周期1s方波
for N in (1, 3, 7, 21, 101):                # 叠加谐波数
    approx = np.zeros_like(t)
    for n in range(1, N+1, 2):              # 只有奇次谐波
        approx += (4/np.pi)*np.sin(2*np.pi*n*t)/n
    plt.plot(t, approx, label=f'N={N}')
plt.legend(); plt.title('傅里叶级数合成与吉布斯现象'); plt.show()

实验五：FIR 滤波器设计与应用

fs = 1000
t = np.arange(0, 1, 1/fs)
x = np.sin(2*np.pi*10*t) + 0.8*np.sin(2*np.pi*200*t)   # 10Hz+200Hz
h = signal.firwin(64, 50, fs=fs)                        # 64阶, 截止50Hz
y = signal.lfilter(h, 1, x)
plt.subplot(211); plt.plot(t[:300], x[:300]); plt.title('滤波前')
plt.subplot(212); plt.plot(t[:300], y[:300]); plt.title('滤波后(200Hz被抑制)')
plt.tight_layout(); plt.show()
