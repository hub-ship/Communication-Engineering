第一章 单片机概述

1.1 什么是单片机

单片机（MCU，Microcontroller Unit）：把 CPU、存储器（ROM/RAM）、IO接口、定时器、串口、ADC 等集成在一块芯片上的微型计算机。"麻雀虽小五脏俱全"。

1.2 单片机 vs 微处理器

单片机(MCU)微处理器(MPU)
定位控制运算
集成外设全集成需外扩芯片
功耗μA~mA级瓦级
系统裸机/RTOSLinux/Windows
典型51/STM32/ESP32i7/树莓派SoC

1.3 主流单片机家族

系列内核特点应用
51系列Intel 8051结构简单、教学经典教学、传统工控
STM32ARM Cortex-M生态最丰富、性价比高万物皆可STM32
ESP32Xtensa/RISC-V自带WiFi/蓝牙物联网
MSP430TI 16位超低功耗仪表
AVR8位RISCArduino御用创客
RISC-V开源指令集自主可控新势力国产MCU
🌱 小白详解 · 新手怎么看懂本章

🔍 通俗理解：单片机 = 把 CPU、内存、IO、外设集成在一个芯片上的"微型计算机"。它和电脑的本质区别：没有操作系统、程序直接控制硬件。家电、仪表、玩具里凡是"按键+显示+控制"的都是它。

📝 例子/口诀：为什么先学 51：它的结构简单到能看懂每一个寄存器，是理解一切现代 MCU（STM32、ESP32）的"骨架"。

⚠️ 易错点：① 分清三个概念：CPU 是芯片、单片机是芯片级小系统、嵌入式系统是"单片机+软件+专用电路"的整机概念；② 看到任何新单片机先问三件事：多少位、主频多少、片上 ROM/RAM 多大。

⭐ 学习重点：单片机 vs 微机 vs 嵌入式的层级关系、MCS-51 基本组成框图、数制与码制基础（BCD/补码）。

第二章 51单片机硬件结构

2.1 引脚与最小系统

最小系统三件套(缺一不能跑):
①电源: VCC(40脚)+5V, GND(20脚)
②时钟: XTAL1/XTAL2 接 11.0592MHz(串口友好)或12MHz晶振 + 2×30pF
③复位: RST(9脚) 高电平复位, 10μF电容+10kΩ电阻上电自动复位
     EA(31脚)接VCC: 使用片内ROM

2.2 存储器结构（哈佛结构）

存储器容量(经典AT89C51)说明
程序存储器 ROM4KB存代码，掉电不丢
数据存储器 RAM128B变量、栈（够用但紧张！）
SFR 特殊功能寄存器128B(80H~FFH)P0~P3、TCON、SCON…

2.3 四个并行IO口

端口特点注意
P0开漏输出，无上拉做IO必须外接上拉电阻(4.7k~10k)
P1准双向口纯IO，最省心
P2准双向口扩展时输出高8位地址
P3复用功能串口/中断/定时器/读写线
🌱 小白详解 · 新手怎么看懂本章

🔍 通俗理解：51 核心记"三区两口"：CPU、ROM（4KB，放程序）、RAM（256B，放变量）、P0~P3 四个 8 位 IO 口。特殊功能寄存器 SFR 区（80H~FFH）是控制整块芯片的"控制面板"。

📝 例子/口诀：时间关系必背：晶振 12MHz 时，时钟周期=1/12μs，机器周期=12 个时钟周期=1μs——以后算定时器初值、写延时函数全靠它。

⚠️ 易错点：① P0 是开漏输出，做普通 IO 必须外接上拉电阻；② RAM 低 128B 直接寻址、高 128B 是 SFR 区（间接寻址访问），地址重叠但物理独立；③ PSW 里的 CY（进位）、AC（辅助进位）、OV（溢出）、P（奇偶）各自含义别张冠李戴。

⭐ 学习重点：P0~P3 各口的第二功能表、PSW 标志位、机器周期与晶振频率的换算。

第三章 Keil C51 与开发流程

3.1 开发环境

  • 编写：Keil μVision（C51）或 VS Code + EIDE 插件
  • 仿真：Proteus（电路仿真，无需硬件）
  • 烧录：STC-ISP（STC芯片）/ 普中自动下载器

3.2 第一个程序：点亮LED

#include <reg52.h>      /* 51寄存器定义头文件 */

sbit LED1 = P1^0;      /* 位定义: P1口第0脚 */

void main(void)
{
    LED1 = 0;          /* 低电平点亮(灌电流,常见接法) */
    while (1)          /* 主循环绝不返回! */
        ;
}

3.3 C51 与标准C的区别

sbit   LED = P1^0;                  /* 位变量,标准C没有 */
unsigned char idata buf[16];        /* idata/data/xdata 指定存储区 */
void t0_isr(void) interrupt 1       /* 中断号1=定时器0,标准C没有 */
{
    TH0 = (65536-50000)/256;        /* 重装初值 */
    TL0 = (65536-50000)%256;
}
🌱 小白详解 · 新手怎么看懂本章

🔍 通俗理解：51 开发五步循环：建工程 → 写 C51 代码 → 编译生成 .hex → 烧录（STC 芯片用 stc-isp 串口下载）→ 上电运行看现象。调试手段主要是 LED 和串口打印。

📝 例子/口诀：Keil 两个必踩的坑都和设置有关：① Target 里没勾 "Create HEX File" 就没有输出文件；② 晶振频率填错，delay 延时全不准。

⚠️ 易错点：① STC 串口下载需要"冷启动"：先点下载按钮、再给板子上电；② Keil 选芯片型号要和实物一致（AT89C52/STC89C52 兼容）；③ C51 与标准 C 的差异：sbit 定义位变量、interrupt 关键字写中断函数、data/xdata 存储区域修饰。

⭐ 学习重点：完整跑通"点亮一个 LED"、理解编译-烧录-运行循环、用 USB 转串口模块连接开发板。

第四章 并行IO应用

4.1 流水灯（数组法+移位法）

#include <reg52.h>
void delay_ms(unsigned int ms)          /* 11.0592MHz近似延时 */
{
    unsigned int i, j;
    for (i = 0; i < ms; i++)
        for (j = 0; j < 114; j++);
}
void main(void)
{
    unsigned char pat[8] = {0xFE,0xFD,0xFB,0xF7,0xEF,0xDF,0xBF,0x7F};
    unsigned char i;
    while (1)
        for (i = 0; i < 8; i++) {
            P1 = pat[i];               /* 查表法 */
            delay_ms(200);
        }
}

4.2 按键检测与消抖

sbit KEY1 = P3^2;
if (KEY1 == 0) {                 /* 检测到按下 */
    delay_ms(10);                /* 延时消抖(机械抖动5~10ms) */
    if (KEY1 == 0) {             /* 确认按下 */
        /* 等待释放,避免长按重复触发 */
        while (KEY1 == 0);
        LED = !LED;              /* 执行动作 */
    }
}
🌱 小白详解 · 新手怎么看懂本章

🔍 通俗理解：点灯是嵌入式的 Hello World。操作 IO 本质就是读写寄存器：P1=0xFE 让 P1.0 输出低电平——LED 是亮是灭取决于电路接法（灌电流接法低电平亮，最常见）。

📝 例子/口诀：流水灯两种写法：移位法（P1=_crol_(P1,1) 循环左移）和查表法（数组存花样）。按键必须消抖：检测到按下→延时 10~20ms→再确认仍按下才算真按。

⚠️ 易错点：① sbit LED=P1^0 之后 LED=0 还是 LED=1 点亮，看原理图接法，背结论没用；② 读 IO 口电平前先写 1（准双向口特性）；③ delay 消抖期间 CPU 什么都不干——后续要用定时器扫描替代。

⭐ 学习重点：流水灯（移位/查表）、独立按键检测+消抖、行列式键盘扫描（行输出列读入）。

第五章 中断系统

5.1 中断的概念

CPU 正在干活时，紧急事件发生 → 暂停当前任务 → 转去处理紧急任务（中断服务函数 ISR）→ 处理完返回继续。相比轮询，中断响应快、效率高、可休眠省电。

5.2 51的五个中断源

中断源中断号默认优先级触发方式
外部中断0 (INT0)0最高低电平/下降沿(IT0=1)
定时器0 (T0)12计数溢出
外部中断1 (INT1)23同INT0
定时器1 (T1)34计数溢出
串口 (UART)4最低发送/接收完成

5.3 中断相关寄存器

IE(中断允许): EA总开关 | ET1/ET0定时器 | EX1/EX0外部 | ES串口
TCON: IT0/IT1触发方式, TF0/TF1溢出标志(硬件置1,进入ISR自动清零)
IP: 中断优先级寄存器(默认自然优先级,可置1提级)
PX0 PT0 PX1 PT1 PS —— 同级中断不能互相打断!

5.4 外部中断实例

#include <reg52.h>
sbit LED = P1^0;

void int0_isr(void) interrupt 0      /* 外部中断0服务函数 */
{
    LED = !LED;                      /* 每次按下翻转 */
}
void main(void)
{
    IT0 = 1;      /* 下降沿触发(低电平触发会连续响应!) */
    EX0 = 1;      /* 允许外部中断0 */
    EA  = 1;      /* 开总中断 */
    while (1) P2 = 0xF0;             /* 主循环干别的事 */
}
⚠️ ISR编写三原则：①越短越好（微秒级，绝不delay）②不用printf等重函数 ③共享变量加 volatile。
🌱 小白详解 · 新手怎么看懂本章

🔍 通俗理解：中断 = 硬件"拍 CPU 的肩膀说有急事"，CPU 保存现场去处理、完事回来继续。比轮询（一直问"来了吗"）高效得多——CPU 平时可以干别的或休眠。

📝 例子/口诀：使用中断四步口诀：EA=1 开总闸 → EX0=1 开分闸 → IT0=1 设触发方式 → 写 interrupt 函数。

⚠️ 易错点：① 中断号对应关系必须背：0=INT0、1=T0、2=INT1、3=T1、4=串口——写错序号程序"看似没反应"；② 中断函数不能有参数、不能有返回值，也不要在里面长延时（阻塞别的代码）；③ 外部中断触发方式选下降沿（IT=1）比低电平可靠——电平不撤销会反复触发。

⭐ 学习重点：五个中断源及优先级（IP 寄存器）、中断响应的现场保护机制、按键改用外部中断实现的写法。

第六章 定时器/计数器

6.1 定时器工作原理

对机器周期（12MHz晶振 = 1μs）或外部脉冲计数，从初值加到 65536 溢出（16位方式）→ TF 置位 → 申请中断。

定时时间 t = (65536 − 初值) × 机器周期　　初值 = 65536 − t / T机器

6.2 四种工作方式（TMOD设置）

方式位数最大定时(12MHz)用途
方式013位8.19ms兼容老芯片
方式116位65.536ms最常用 ⭐
方式28位自动重装256μs串口波特率发生器
方式3T0拆双8位—极少用

6.3 定时器0方式1：50ms精确定时

/* 11.0592MHz: 机器周期=1.085μs, 50ms需要46080个周期 */
/* 初值 = 65536-46080 = 19456 = 0x4C00 */
#include <reg52.h>
unsigned char cnt = 0;
void timer0_isr(void) interrupt 1
{
    TH0 = 0x4C; TL0 = 0x00;       /* 必须手动重装! */
    if (++cnt >= 20) {            /* 20×50ms = 1秒 */
        cnt = 0;
        P1 = ~P1;                 /* 每秒翻转 */
    }
}
void main(void)
{
    TMOD = 0x01;        /* T0方式1(16位定时) */
    TH0 = 0x4C; TL0 = 0x00;
    ET0 = 1; EA = 1;    /* 允许T0中断,开总中断 */
    TR0 = 1;            /* 启动定时器 */
    while (1);
}

6.4 PWM软件模拟

/* 定时器产生PWM控制LED亮度/电机调速 */
void t0_isr(void) interrupt 1
{
    static unsigned char duty = 0, tick = 0;
    TH0 = 0xFF; TL0 = 0x00;        /* 256μs一拍(方式1快装) */
    if (++tick >= 100) tick = 0;   /* 周期100拍=25.6ms */
    LED = (tick < duty) ? 0 : 1;   /* 前 duty 拍点亮 */
}
🌱 小白详解 · 新手怎么看懂本章

🔍 通俗理解：定时器本质是"数机器周期的计数器"：每来一个机器周期加 1，数到溢出（TF 置位）就申请中断。它的价值是让 CPU 从"死等延时"中解放出来。

📝 例子/口诀：初值计算模板：12MHz、模式1（16位）、要定时 50ms → 需计 50000 个机器周期 → 初值 = 65536−50000 = 15536 = 0x3CB0 → TH0=0x3C、TL0=0xB0。要 1 秒就中断 20 次再计数。

⚠️ 易错点：① TMOD 低 4 位管 T0、高 4 位管 T1，别写反；② 模式 2（8 位自动重装）适合产生串口波特率，模式 1 适合长定时；③ 中断方式下 TF 自动清零，查询方式必须手动清 TF。

⭐ 学习重点：定时器初始化四步、任意时长的精确定时（中断计数法）、定时器中断产生方波/PWM 的思路。

第七章 串行通信（UART）

7.1 通信方式基础

并行串行
线路多位同时传一位一位传
速度快相对慢
成本高（排线）低（1~2根线）
距离短长
串行方向说明典型
单工只能单向遥控器
半双工双向不同时RS485、对讲机
全双工双向同时UART(TXD/RXD)、RS232

7.2 UART帧格式

空闲(高) → 起始位(低) → D0 D1 ... D7(低位在前) → 奇偶校验(可选) → 停止位(高)
一帧 = 10位(8N1格式: 8数据无校验1停止)最常用
波特率 9600 → 每位时间 = 1/9600 ≈ 104μs

7.3 波特率设置（方式1+T1方式2）

波特率 = (2SMOD/32) × fosc / (12 × (256 − 初值))
/* 11.0592MHz, 9600bps, SMOD=0 → 初值=0xFD(253) */
void uart_init(void)
{
    SCON = 0x50;        /* 方式1(8位UART), 允许接收(REN=1) */
    TMOD |= 0x20;       /* T1方式2(8位自动重装)做波特率发生器 */
    TH1 = TL1 = 0xFD;   /* 9600bps @11.0592MHz */
    TR1 = 1;            /* 启动T1 */
    ES = 1; EA = 1;     /* 允许串口中断 */
}
/* 这就是为什么大家都用11.0592MHz晶振——波特率误差为0! */
/* 1200→0xE8, 2400→0xF4, 4800→0xFA, 9600→0xFD, 19200→0xFD且SMOD=1 */

7.4 收发实现

void uart_send(unsigned char dat)
{
    ES = 0;             /* 发送期间关串口中断,防自扰 */
    TI = 0;             /* 清发送标志 */
    SBUF = dat;         /* 写SBUF自动启动发送 */
    while (!TI);        /* 等待发送完成 */
    ES = 1;
}
void uart_isr(void) interrupt 4
{
    if (RI) {           /* 收到一字节 */
        RI = 0;         /* 软件清零接收标志 */
        rx_buf = SBUF;  /* 读取数据(读SBUF自动取接收缓存) */
        rx_flag = 1;
    }
}

7.5 RS232 / RS485 / TTL 电平

标准电平距离场景
TTL0/5V板内芯片之间
RS232±3~15V(MAX232转换)15m老式工控/调试口
RS485差分信号(MAX485)1200mModbus工业总线
🌱 小白详解 · 新手怎么看懂本章

🔍 通俗理解：串口是单片机和电脑、其他芯片对话的通道。通信双方必须约好参数——最常用"9600, 8, N, 1"（波特率 9600、8 位数据、无校验、1 位停止）。

📝 例子/口诀：初始化五件套：SCON=0x50（模式1+允许接收）→ TMOD 设 T1 模式2 → TH1=0xFD（9600@11.0592MHz）→ TR1=1 → ES=1、EA=1。

⚠️ 易错点：① 为什么用 11.0592MHz 晶振：12MHz 分频有误差、收发会乱码，11.0592 能整除出精确波特率；② 发送完 TI 要软件清零、接收完 RI 同理，否则下一次收发失效；③ printf 重定向需要重写 putchar。

⭐ 学习重点：串口初始化代码默写、发送/接收单字节与字符串、电脑端串口助手联调（这是最实用的调试手段）。

第八章 数码管与键盘

8.1 数码管静态与动态显示

/* 共阴极段码表(共阳则取反) */
unsigned char code seg[] = {       /* code关键字:存ROM省RAM */
    0x3F,0x06,0x5B,0x4F,0x66,      /* 0 1 2 3 4 */
    0x6D,0x7D,0x07,0x7F,0x6F};     /* 5 6 7 8 9 */

/* 动态扫描: 4位数码管轮流点亮,利用视觉暂留(>50Hz无闪烁) */
void display(unsigned char pos, unsigned char num)
{
    P2 = ~(1 << pos);    /* 位选(38译码器/直接IO) */
    P0 = seg[num];        /* 段选 */
    delay_ms(2);          /* 点亮2ms后切下一位 */
}

8.2 矩阵键盘扫描（4×4）

/* 行列扫描法: 行输出、列读回 */
unsigned char key_scan(void)
{
    unsigned char row, col, tmp;
    P1 = 0xF0;                       /* 行全低,列上拉 */
    if (P1 != 0xF0) {                /* 有键按下 */
        delay_ms(10);                /* 消抖 */
        if (P1 != 0xF0) {
            tmp = P1 & 0xF0;
            for (row = 0; row < 4; row++) {       /* 定位列 */
                ...
            }
            /* 或线反转法: 先送0xF0读列,再送0x0F读行,两次结果合成键码 */
            while (P1 != 0xF0);      /* 等待释放 */
            return key_code;         /* 返回0~15键值 */
        }
    }
    return 0xFF;                     /* 无键 */
}
🌱 小白详解 · 新手怎么看懂本章

🔍 通俗理解：数码管 = 8 段 LED 按一定排列组成。分共阴（公共端接地，段码高电平亮）和共阳（段码低电平亮）——两种段码表互为取反。

📝 例子/口诀：多位数码管用动态扫描：轮流快速点亮每一位（每位 1~2ms、整体刷新率 >50Hz），靠人眼视觉暂留看起来"同时亮"。N 位只占 8+N 根线。

⚠️ 易错点：① 动态扫描每位点亮时间太长会闪、太短会暗，1~2ms 是经验值；② 段码表加 code 关键字存 ROM，省宝贵的 RAM；③ 行列键盘扫描：行输出逐行拉低、列读入判断哪键按下，松手检测别忘了。

⭐ 学习重点：共阴/共阳段码计算、动态扫描程序框架（配合定时器中断刷新，避免 delay 阻塞）、4×4 键盘扫描+键值显示。

9.1 LCD1602 驱动

#define LCD_DATA P0        /* 数据口 */
sbit LCD_RS = P2^6;         /* 0命令 1数据 */
sbit LCD_RW = P2^5;         /* 0写 1读 */
sbit LCD_EN = P2^7;         /* 使能,下降沿锁存 */

void lcd_write(bit rs, unsigned char d)
{
    LCD_RS = rs; LCD_RW = 0;
    LCD_DATA = d;
    LCD_EN = 1; delay_us(5);
    LCD_EN = 0;             /* EN高脉冲写入 */
}
void lcd_init(void)
{
    delay_ms(15);

    lcd_write(0, 0x0C);     /* 开显示,关光标 */

    lcd_write(0, 0x01);     /* 清屏 */

}
void lcd_show(unsigned char pos, char *s)   /* pos:0x80+地址 */
{

}

📝 例子/口诀：操作时序一句话：RS=0 写指令、RS=1 写数据，配合 E 引脚的高脉冲锁存。初始化必须严格按手册顺序发指令序列。

⭐ 学习重点：1602 初始化流程与显示字符串、自定义字符（CGRAM）、12864 画点与汉字显示原理。

第十章 I2C 与 SPI 总线

10.1 I2C 总线（两线制）

两根线: SDA数据 + SCL时钟(均需上拉电阻4.7k)
器件地址7位 + 读写位 → 每个器件天然编址
信号: 起始S(SCL高时SDA下降沿) / 停止P(SCL高时SDA上升沿)
     应答ACK(第9个时钟SDA拉低)
时钟最高400kHz(快速模式)
典型器件: AT24C02(EEPROM)、DS1307(RTC)、OLED(SSD1306)

10.2 GPIO 模拟 I2C 时序（读EEPROM）

sbit SDA = P2^0;  sbit SCL = P2^1;

void i2c_start(void) { SDA=1; SCL=1; delay_us(4); SDA=0; delay_us(4); SCL=0; }
void i2c_stop(void)  { SDA=0; SCL=1; delay_us(4); SDA=1; delay_us(4); }
bit   i2c_wait_ack(void) { SDA=1; SCL=1; delay_us(4); SCL=0; return SDA?1:0; }

void i2c_write_byte(unsigned char d)
{
    unsigned char i;
    for (i = 0; i < 8; i++) {
        SDA = (d & 0x80) ? 1 : 0;    /* 高位在前 */
        SCL = 1; delay_us(4); SCL = 0;
        d <<= 1;
    }
}
/* 24C02读一字节: START → 0xA0(写器件地址) → 字节地址 → 
   START(重复起始) → 0xA1(读) → 收数据 → NACK → STOP */

10.3 SPI 总线（四线制，更快）

信号作用
SCK时钟（主机产生）
MOSI主机出从机入
MISO主机入从机出
CS/SS片选（低有效，选器件）
特点: 全双工、时钟可达几十MHz、无应答机制
CPOL/CPHA四种模式(模式0最常用: SCL空闲低,第一个边沿采样)
典型器件: W25Q64(Flash)、NRF24L01(无线)、SD卡、TFT屏

10.4 I2C vs SPI 选择

I2CSPI
线数24(+每器件1片选)
速度≤3.4MHz几十MHz
寻址协议内建硬件片选
场景慢速传感器多挂大容量快速传输
🌱 小白详解 · 新手怎么看懂本章

🔍 通俗理解：I2C = 两线总线（SDA 数据 + SCL 时钟），靠 7 位地址区分挂在同一对线上的多个器件；SPI = 四线（MOSI/MISO/SCK/CS），更快但每个从设备要一根片选线。51 没有硬件 I2C/SPI，需要 GPIO 软件"演"出时序。

📝 例子/口诀：I2C 起始条件：SCL 高电平时 SDA 由高变低；停止条件相反。每传 8 位后第 9 个时钟是应答位（从机拉低 SDA 表示 ACK）。

⚠️ 易错点：① 24C02 这类 EEPROM 的器件地址 = 固定高 4 位 + 硬件接线低 3 位；② SPI 四种模式（CPOL/CPHA 组合）由从设备手册指定，主从必须一致；③ 软件 I2C 的延时不达标会通信失败——示波器/逻辑分析仪是最好的排错工具。

⭐ 学习重点：软件模拟 I2C 读写 EEPROM 全流程（起始→器件地址→存储地址→数据→停止）、SPI 驱动一个外设（如 Flash/显示屏）。

第十一章 A/D 与 D/A 转换

11.1 ADC 关键指标

分辨率：n位 → 把 Vref 分成 2ⁿ 份，1LSB = Vref/2ⁿ
  • 8位 ADC（ADC0809）：256级
  • 10位（51内置如STC15）：1024级
  • 12位（STM32内置ADC、TLC2543）：4096级
  • 转换时间、采样保持、参考电压稳定性同样重要

11.2 ADC0809 接口（经典教学芯片）

8路模拟开关 + 8位逐次逼近ADC
控制: START启动 / EOC转换结束 / OE输出允许 / ALE锁存通道地址
时钟CLOCK: 500kHz(由ALE分频或外部提供)
流程: 选通道(IN0~IN7) → ALE锁存 → START脉冲 → 等EOC=1 → OE=1读数据

11.3 电压采集实战（数字电压表）

unsigned char adc_read(unsigned char ch)
{
    unsigned char dat;
    ADC_CH = ch & 0x07;      /* P2低3位选通道 */
    ST = 0; ST = 1; ST = 0;   /* START正脉冲启动 */
    while (!EOC);             /* 等待转换完成 */
    OE = 1;                   /* 打开输出 */
    dat = ADC_DATA;           /* 读8位结果 */
    OE = 0;
    return dat;
}
/* 显示: 电压 = dat × 5.0 / 255,保留两位小数(×100转整数避免浮点) */
unsigned int mv = (unsigned int)dat * 500UL / 255;
disp_num(mv / 100, mv % 100);   /* X.XX格式 */

11.4 DAC0832 输出波形

/* 8位电流输出DAC,运放转电压: Vout = -D×Vref/256 */
/* 定时器中断查表输出正弦波 */
unsigned char code sine_tab[64] = {128,140,152,...};  /* 64点正弦表 */
void t0_isr(void) interrupt 1
{
    static unsigned char i = 0;
    TH0 = 0xFF; TL0 = 0x00;      /* 256μs → 输出频率≈61Hz */
    DAC_DATA = sine_tab[i++ & 63];
}
🌱 小白详解 · 新手怎么看懂本章

🔍 通俗理解：A/D 把模拟电压变成数字量（传感器→单片机的必经之路），D/A 反过来。两个关键指标：位数（8 位 = 256 级）和参考电压（决定满量程）。

📝 例子/口诀：换算公式一条：数字量 = 输入电压/参考电压 × (2ⁿ−1)。例：3.3V 参考、8 位 ADC、输入 1V → 1/3.3×255 ≈ 77。

⚠️ 易错点：① 采样时间要足够（内部采样电容要充电），时钟太快读数会漂；② 参考电压的稳定性直接决定精度，Vref 加电容滤波；③ 结果寄存器有左对齐/右对齐两种配置，读之前看清楚。

⭐ 学习重点：用 PCF8591（I2C 接口的 4 路 ADC+1 路 DAC）做电压表/光强检测、数字量转电压显示的小数处理。

第十三章 习题与思考

1.（计算）12MHz晶振，定时器方式1，要定时20ms，初值是多少？TH0/TL0各取何值？

机器周期 = 12/12MHz = 1μs。计数值 = 20ms/1μs = 20000。
初值 = 65536 − 20000 = 45536 = 0xB1E0 → TH0 = 0xB1，TL0 = 0xE0。

2.（思考）为什么51的串口常用11.0592MHz而不是12MHz晶振？

方式1波特率 = (2SMOD/32)×fosc/(12×(256−初值))。11.0592MHz 能被常用波特率整除（11.0592MHz/12/32/9600 = 3 → 初值253，误差为0）；而12MHz 得出的初值必须取整，波特率误差达百分之几，通信会出错。这是工程选型"参数优先于直觉"的经典案例。

3.（概念）中断和轮询各有什么优缺点？各举一个适用场景。

轮询：实现简单、时序确定，但CPU空转浪费、响应不及时。适合：主循环刷新数码管。
中断：响应快、CPU可休眠省电，但程序流程不直观、有重入风险。适合：串口接收、按键紧急处理、定时采样。
实际系统混合使用：中断置标志，主循环处理业务（"前后台架构"）。

4.（改错）以下定时器初始化代码有什么隐患？ 
void main(void)
{
    TMOD = 0x01;
    TR0 = 1;
    EA = 1;
    while (1);
}
void t0_isr(void) interrupt 1
{
    P1 = ~P1;          /* 问题: 方式1不会自动重装初值! */
}                       /* 每次溢出后从0开始计,定时变成65.536ms */
/* 修正: 初始化时和ISR中都装 TH0/TL0 初值 */
5.（思考）动态扫描数码管为什么不会看到闪烁？闪烁了怎么排查？

每位点亮几 ms 后切换，只要整轮刷新率 ≥ 50Hz（每轮 < 20ms），人眼视觉暂留就觉得全部同时亮。若某段代码（delay/长ISR）打断扫描导致刷新率低于 50Hz 就会闪烁。排查：测量单轮扫描时间；把扫描放到定时器中断保证节拍；缩短ISR。

6.（计算）4位共阴数码管动态扫描，每位点亮2ms，一轮刷新耗时多少？刷新率多少？满足无闪烁要求吗？

一轮 = 4×2ms = 8ms → 刷新率 = 1/0.008 = 125Hz > 50Hz，满足。注意这要求主循环每 8ms 完整跑一遍扫描函数，若中间插入长延时会拉低刷新率。

7.（设计）单片机采集 0~5V 模拟电压并经串口每秒上传一次，给出系统框图与关键参数。

框图：电位器(0~5V) → ADC0809/片内ADC → 51计算电压 → UART(TXD) → USB转TTL → PC串口助手。
关键参数：ADC 8位（1LSB≈19.6mV）；采样由定时器1Hz触发或主循环轮询；波特率9600（初值0xFD@11.0592MHz）；上传格式如 "V=2.45V\r\n"（ASCII可直接显示）；电压换算用整数运算 mv=dat*500/255 避免浮点库。

项目二：串口控制RGB灯（命令解析）

/* 协议: "R:255\n" "G:100\n" "B:0\n" 设置各通道亮度(PWM)
   知识点: 串口中断接收, 缓冲区组包, 简单协议解析, atoi */
volatile char rxBuf[16];
volatile bit rxDone = 0;

void uart_isr(void) interrupt 4
{
    static unsigned char i = 0;
    if (RI) {
        RI = 0;
        char c = SBUF;
        if (c == '\n') { rxBuf[i] = 0; i = 0; rxDone = 1; }
        else if (i < sizeof(rxBuf)-1) rxBuf[i++] = c;
    }
}
void main(void)
{
    uart_init();

        if (rxDone) {
            rxDone = 0;
            if (rxBuf[0]=='R') pwm_r = atoi(&rxBuf[2]);
            else if (rxBuf[0]=='G') pwm_g = atoi(&rxBuf[2]);
            else if (rxBuf[0]=='B') pwm_b = atoi(&rxBuf[2]);
        }
        pwm_update();
    }
}

项目三：DS18B20 温度计（单总线）

/* DS18B20: 单总线(1-Wire)数字温度传感器
   时序: 复位(拉低480~960μs) → ROM命令(0xCC跳过) 
        → 功能命令(0x44启动转换) → 等750ms → 0xBE读暂存器
   温度 = 读取16位(补码,低位在前) × 0.0625℃ */
float read_temp(void)
{
    unsigned char L, H;
    ds_reset(); ds_write(0xCC); ds_write(0x44);
    delay_ms(750);
    ds_reset(); ds_write(0xCC); ds_write(0xBE);
    L = ds_read(); H = ds_read();
    return ((H << 8) | L) * 0.0625;
}
