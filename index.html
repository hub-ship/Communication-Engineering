≡ 一、什么是通信工程？

📖 专业定义

通信工程（Electronic Information Engineering / Telecommunications Engineering）是电子信息类下的核心工科专业，专业代码 080713。它研究信息的产生、传输、交换、处理与存储，覆盖电路与系统、信号处理、通信网络、无线传输、光通信、卫星通信等领域。

一句话概括：让信息以最快、最稳、最省资源的方式，从 A 点抵达 B 点 —— 这是通信工程永恒的命题。

🎯 培养目标

  • 掌握通信系统（调制解调、信道编码、同步、组网）理论基础
  • 具备软硬件协同开发能力（C / 嵌入式 / FPGA / Python）
  • 理解主流标准（3GPP / IEEE 802.11 / TCP-IP）
  • 拥有工程实践能力（仿真、SDR、5G 基站、协议分析）
  • 具备持续学习能力（行业每 10 年一次代际跃迁）

≡ 二、通信工程 · 四年学习路线图

从大一上 → 大四下，一条贯通的主线，覆盖数学 · 编程 · 硬件 · 信号 · 通信 · 网络 · 协议 · 方向的全部核心课程。前序课是后序课的必要前置，箭头方向即学习方向。

1
大一上基础 Ⅰ · 数理编程底子
高等数学 Ⅰ 线性代数 大学物理 电路分析基础 C 语言程序设计
🎯 目标：数学工具入门、第一个能跑通的 C 程序、认识"电路=电流"概念
2
大一下基础 Ⅱ · 概率与硬件
高等数学 Ⅱ 概率论与数理统计 模拟电子技术 数字电子技术 工程制图 / 复变函数
🎯 目标：概率统计为通信噪声打底；模电数电构建硬件思维
3
大二上信号底座 · 三大变换
信号与系统 复变函数与积分变换 电路原理进阶 数据结构
🎯 目标：搞定卷积 / 傅里叶 / 拉普拉斯 / Z 变换，这是后续所有通信课的共同语言
4
大二下专业核心 Ⅰ · 通信入门
通信原理 电磁场与电磁波 微机原理 Matlab 仿真实践
🎯 目标：理解调制 · 解调 · 信道 · 编码的概念级图像，会用 MATLAB 画星座图
5
大三上专业核心 Ⅱ · 嵌入式
单片机原理与应用 操作系统 & Linux 数字信号处理（DSP） FPGA / Verilog
🎯 目标：会写 STM32 串口 / 中断 / DMA，能在 Linux 下写 socket、编译内核模块
6
大三下系统级 · 网络与无线
数据通信与计算机网络 移动通信（2G→5G） 天线与电波传播 Python 工具链
🎯 目标：能讲清TCP/IP 协议栈、5G NR 帧结构、SDR 概念，可读懂 3GPP 协议
7
大四上方向分化 · 选 1-2 钻深
📡 无线通信（OFDM / MIMO / 信道估计） 🔧 嵌入式 / IoT（RTOS / 边缘 AI） 🛰 卫星 / 光通信 / 雷达 🤖 通信 + AI（深度学习信道、语义通信）
🎯 目标：选定毕设方向 + 就业方向，把 1-2 个方向做到能写进简历
8
大四下毕业出口 · 产出
📝 毕业论文 / 设计 💼 秋招 / 春招 / 实习转正 📚 读研 / 出国深造 🚀 创业 / 竞赛成果转化
✅ 完成：7 门课 + 1 个方向 + 1 份可展示项目 = 进入通信行业或读研的入场券

📈 经验法则

本科毕业 3 年内主要比拼 项目 + 编码；5 年以上拼 系统能力 + 标准理解；8 年以上拼 架构 + 行业判断。通信是"慢热型"工科，工龄越长越值钱。

≡ 七、常见问题 · 新生 & 转行答疑

❓ 通信工程是不是"天坑"？

不是。通信工程就业面比想象中宽 —— 因为所有硬件都要"通信"，从手机、芯片、智能车到机器人、卫星、雷达都离不开。本科阶段扎实学好数学 + C 语言 + 通信原理 + 信号与系统，就能在大多数方向上站稳，再读个研就能进核心算法岗。

❓ 通信工程 vs 计算机 / 电子信息 / 自动化怎么选？

想搞算法 / 软件 / AI：可考虑计算机或通信+AI 双背景；想搞芯片 / 射频 / 硬件：通信或电子信息更对口；想搞控制 / 机器人：自动化/机器人。通信工程的最大优势是横跨"软硬件 + 算法"，兼容性最高。

❓ 数学/物理不好能学通信工程吗？

高中数学/物理中等以上即可。本科阶段高数、线代、概率、复变是核心工具。建议把数学当成工具而非负担，多在 MATLAB / Python 里"算"出图像来理解，效率远高于死记硬背。

❓ 要不要考研？

如果目标是设备商研发 / 芯片公司 / 算法岗 / 高薪方向，几乎必须读研（专硕 2-3 年性价比最高）。如果目标是互联网后端 / 运维 / 国企 / 公务员，本科就业也很顺畅，没有"必须读研"的说法。

❓ 自学路线怎么走？

本站的7 门核心课程已对应通信工程本科最核心的知识点。建议按 学习路线图 顺序：C 语言 → 信号与系统 → 通信原理 → 单片机 → 数据通信与网络 → 移动通信 → OS & Linux。每门课配 MATLAB / Python 仿真，务必动手做。
