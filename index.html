≡ 一、什么是通信工程？

📖 专业定义

通信工程（Electronic Information Engineering / Telecommunications Engineering）是电子信息类下的核心工科专业，专业代码 080713。它研究信息的产生、传输、交换、处理与存储，覆盖电路与系统、信号处理、通信网络、无线传输、光通信、卫星通信等领域。

一句话概括：让信息以最快、最稳、最省资源的方式，从 A 点抵达 B 点 —— 这是通信工程永恒的命题。

🎯 培养目标

  • 掌握通信系统（调制解调、信道编码、同步、组网）理论基础
  • 具备软硬件协同开发能力（C / 嵌入式 / FPGA / Python）
  • 理解主流标准（3GPP / IEEE 802.11 / TCP-IP）
  • 拥有工程实践能力（仿真、SDR、5G 基站、协议分析）
  • 具备持续学习能力（行业每 10 年一次代际跃迁）

≡ 二、通信工程 · 核心课程学习路线（7 本书）

从 编程底座 → 信号底座 → 通信核心 → 无线 + 嵌入式 → 系统层，5 个阶段覆盖你给的 7 本指定教材。前序阶段是后序阶段的必要前置，箭头方向即学习方向。
节奏：总时长 11~16 个月（按每周 10~15 小时计，半年到一年内可全部通关）。
📌 扩展推荐（电路、模数电、概率论、数据结构等）不在图中，详见 「七、推荐资源」。

1
阶段 1 · 编程底座 1~2 月 编程 · 入场
C 语言程序设计（谭浩强）
🎯 目标：写 200 行小程序无障碍、指针 / 链表 / 结构体熟练；为后面单片机 · OS打地基
2
阶段 2 · 信号底座 2~3 月 信号 · 数学语言
信号与系统（陈后金）
🎯 目标：掌握卷积 / 傅里叶 / 拉氏变换三大语言；这是通信原理的唯一必要前置
3
阶段 3 · 通信核心 3~4 月 物理层 + 协议栈
通信原理（杨洁王琪） 数据通信与网络技术（华为）
🎯 二者可并行：前者讲调制 / 信道 / 编码，后者讲 TCP/IP 协议栈；阶段 3 完成时你能讲清一个比特从应用到天线的全过程
4
阶段 4 · 无线 + 嵌入式 3~4 月 无线 · 硬件控制
移动通信原理（陈威兵张刚林） ARM Cortex-M3 单片机（黄克亚）
🎯 二者可并行：移动通信讲 2G~5G 空口演进，单片机讲 STM32 实操；简历 / 毕设的双亮点
5
阶段 5 · 系统层 🟧 2~3 月 出口 · 出师
计算机操作系统（汤小丹）
🎯 目标：进程 / 内存 / 文件核心概念 + Linux 命令 + Shell 脚本；为毕设 / 读研 / 就业打最后一枪
📌 扩展推荐（仅供参考，不在图中）：电路分析 · 模电 · 数电 · 概率论 · 线性代数 · 数据结构 · MATLAB · 电磁场 · DSP/FPGA。
详细清单见 「七、推荐资源 · 持续学习入口」；每门课程页末尾也单列了配套学习资源。

≡ 五、常见问题 · 新生 & 转行答疑

❓ 通信工程是不是"天坑"？

不是。通信工程就业面比想象中宽 —— 因为所有硬件都要"通信"，从手机、芯片、智能车到机器人、卫星、雷达都离不开。本科阶段扎实学好数学 + C 语言 + 通信原理 + 信号与系统，就能在大多数方向上站稳，再读个研就能进核心算法岗。

❓ 通信工程 vs 计算机 / 电子信息 / 自动化怎么选？

想搞算法 / 软件 / AI：可考虑计算机或通信+AI 双背景；想搞芯片 / 射频 / 硬件：通信或电子信息更对口；想搞控制 / 机器人：自动化/机器人。通信工程的最大优势是横跨"软硬件 + 算法"，兼容性最高。

❓ 自学路线怎么走？

本站的 7 门核心课程 = 你给定的 7 本教材。推荐按 核心课程学习路线 5 阶段顺序：C 语言 → 信号与系统 → 通信原理 / 数据通信 → 移动通信 / 单片机 → OS & Linux。每门课配 MATLAB / Python 仿真，务必动手做。
