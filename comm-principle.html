第一章 通信系统概述

1.1 通信的基本概念

通信：信息的传输与交换。消息（Message）是信息的载体，信息（Information）是消息中不确定性的消除。

1.2 通信系统一般模型

信源 → 信源编码 → 信道编码 → 调制 → 信道(+噪声) → 解调 → 信道译码 → 信源译码 → 信宿
模块作用典型技术
信源编码压缩冗余，提高有效性Huffman、MP3、H.264
信道编码增加冗余，提高可靠性汉明码、卷积码、LDPC
调制频谱搬移，匹配信道AM、FM、QAM、OFDM
信道传输媒介双绞线、光纤、自由空间
💡 有效性 vs 可靠性：信源编码去冗余提高有效性，信道编码加冗余提高可靠性 —— 二者是矛盾的统一，这是通信系统设计永恒的权衡。

1.3 通信系统分类

  • 按信号：模拟通信系统 / 数字通信系统
  • 按媒介：有线（明线/电缆/光纤）/ 无线（地波/天波/视线）
  • 按复用：FDM（频分）/ TDM（时分）/ CDM（码分）/ OFDM（正交频分）

1.4 信息度量（香农信息熵）

I = log2(1/P(x)) （比特 bit）
信源熵 H(X) = −Σ P(xi) log2 P(xi) bit/符号

等概二进制信源：H = 1 bit/符号（每符号信息量最大）。

1.5 通信系统主要性能指标

指标模拟系统数字系统
有效性带宽 B频带利用率 η = RB/B (Baud/Hz)
可靠性信噪比 SNR误码率 Pe、误信率 Pb

第二章 信道与噪声

2.1 信道的数学模型

调制信道模型：y(t) = k(t)·x(t) + n(t)，其中 k(t) 为乘性干扰（衰落），n(t) 为加性噪声。

  • 恒参信道：k(t) 基本不变 —— 有线信道、微波视距中继（幅频失真、相频失真可用均衡器补偿）
  • 随参信道：k(t) 随机变化 —— 短波电离层反射、移动信道（产生多径衰落、多普勒频移）

2.2 高斯白噪声与窄带噪声

  • 白噪声：功率谱密度 Pn(f) = n0/2（双边），对所有频率均匀分布
  • 高斯噪声：幅度服从高斯（正态）分布
  • AWGN：加性高斯白噪声，通信理论分析的标准噪声模型

2.3 多径传播与瑞利衰落

移动环境下信号经多条路径到达接收端，合成信号包络服从瑞利分布（无直射径）或莱斯分布（有直射径）。

多径时延扩展 τm → 相关带宽 Bc ≈ 1/τm

信号带宽 > Bc 时发生频率选择性衰落；反之称为平坦衰落。这是 OFDM 划分子载波的根本依据。

2.4 信道容量（香农公式）

C = B·log2(1 + S/N) （bit/s）
  • 提高容量三条路：增大带宽 B、增大信号功率 S、降低噪声 N
  • B → ∞ 时 C → (S/n0)·log2e，即香农极限
  • 意义：给出了无差错传输的速率上限，是 5G、Wi-Fi 等所有系统逼近的理论天花板

第三章 模拟幅度调制

3.1 常规调幅（AM）

sAM(t) = [A + m(t)]·cos(ωct)

要求 |m(t)|max ≤ A（否则过调制失真）。已调波包含载波 + 上下边带。

项目AMDSBSSBVSB
带宽2fH2fHfH介于两者间
功率效率低（载波占大半）高最高较高
解调包络检波（简单！）相干解调相干解调相干/插入载波
应用中波广播立体声副信道短波/频谱紧张模拟电视

3.2 包络检波原理

利用二极管 + RC 电路跟踪已调波包络，无需本地载波，接收机极其简单 —— 这就是收音机用 AM 的原因。

3.3 相干解调（同步检波）

s(t)·cos(ωct) → 低通滤波 → (1/2)m(t)

需要接收端产生与发送端同频同相的本地载波（同步问题见第十一章）。

第四章 角度调制（FM / PM）

4.1 基本概念

调频 FM：瞬时频率随 m(t) 线性变化 —— ω(t) = ωc + Kf·m(t)
调相 PM：瞬时相位随 m(t) 线性变化 —— θ(t) = ωct + Kp·m(t)

4.2 FM 频谱与卡森带宽

调频指数 mf = Δf / fm　　BFM = 2(mf+1)fm = 2(Δf + fm)（卡森公式）
  • 窄带 FM（mf ≪ 1）：B ≈ 2fm，与 AM 相同
  • 宽带 FM（mf ≫ 1）：B ≈ 2Δf，带宽换取信噪比增益的典型体现

4.3 FM 的抗噪声性能

大信噪比下制度增益 GFM ≈ 3mf2(mf+1)
✅ 以带宽换信噪比：FM 通过增加带宽可大幅提升解调输出信噪比，这是"有效性换可靠性"的经典范例，也是 FM 音质优于 AM 的根本原因。调频广播 Δf = 75 kHz、电视伴音均用 FM。

4.4 门限效应

小信噪比时包络检波（AM）和 FM 鉴频都出现输出信噪比急剧恶化的门限效应。采用锁相环(PLL)鉴频、预加重/去加重可改善门限。

第五章 抽样定理与脉冲调制

5.1 低通抽样定理（奈奎斯特）

fs ≥ 2fH （奈奎斯特速率），否则产生混叠失真

一个频带限制在 [0, fH] 的模拟信号，可以用间隔 Ts = 1/(2fH) 的离散样值无失真重建。电话语音 fH = 3.4 kHz，取 fs = 8 kHz 留保护带。

5.2 脉冲模拟调制家族

方式被调参数特点
PAM 脉幅调制脉冲幅度抽样本身，未量化
PDM/PWM 脉宽调制脉冲宽度开关电源、舵机控制
PPM 脉位调制脉冲位置抗幅噪能力强

5.3 量化

  • 均匀量化：小信号量化信噪比差
  • 非均匀量化（A律/μ律）：小信号密、大信号疏，量化信噪比趋于均匀。中国/欧洲用 A律(13折线)，北美用 μ律
量化信噪比 SQNR ≈ 6.02N + 1.76 dB（N 为量化位数）

每增加 1 bit 量化位数，信噪比提升约 6 dB —— ADC 选型的核心公式。

第六章 PCM 脉冲编码调制

6.1 PCM 三步曲

模拟信号 → ①抽样(时间离散) → ②量化(幅度离散) → ③编码(二进制表示) → PCM 数字信号

6.2 A律13折线编码

8 位 PCM 码字：极性码 C1 + 段落码 C2C3C4 + 段内码 C5C6C7C8。

参数数值
抽样率8000 Hz
每样值比特数8 bit（1+3+4）
PCM 话路速率64 kbit/s（G.711）
30/32 路 PCM 基群（E1）2.048 Mbit/s

6.3 PCM 系统抗噪性能

输出总信噪比 = 量化信噪比 + 误码信噪比　　(SNR)dB ≈ 6N + 2 − 10lg(1/(1−Pe2))

6.4 增量调制（ΔM）与 DPCM

  • ΔM：每样值只编 1 bit（预测误差符号），简单但有过载量化噪声
  • DPCM：对预测误差多比特量化，图像编码（如 H.264 帧内预测）的基础

第七章 数字基带传输

7.1 常用基带波形

码型特点适用
单极性 NRZ有直流、无定时分量近距离/芯片内部
双极性 NRZ无直流（等概时）通用
AMI 码0→0，1→交替±1；无直流、可检错电话基带
HDB3 码AMI + 连零抑制（最多3连0）E1 传输标准 ⭐
曼彻斯特码每比特中央跳变，自带时钟以太网 10BASE-T
CMI 码1→11/00 交替，0→01SDH 光接口

7.2 码间串扰（ISI）与奈奎斯特第一准则

Σ ak·h(t−kTs) 中，抽样时刻 h(0)≠0、h(kTs)=0（k≠0）→ 无码间串扰

理想低通：B = RB/2，极限频带利用率 2 Baud/Hz（极限不可实现）；
升余弦滚降：B = (1+α)·RB/2，拖尾衰减快、可实现，α 为滚降系数。

7.3 眼图

示波器上重叠显示的基带波形 —— "眼睛"张开越大，码间串扰越小、噪声容限越大；眼睛闭合时刻即最佳抽样时刻。工程调测基带系统的第一工具。

7.4 部分响应与均衡

  • 部分响应技术：有意引入可控 ISI（相关电平编码），逼近 2 Baud/Hz 的极限利用率
  • 时域均衡：横向滤波器消除信道失真（判决反馈均衡 DFE、最大似然序列检测 MLSE）

第八章 二进制数字调制

8.1 三种基本方式

方式表达式变化带宽误码率（相干）
2ASK/OOK幅度 0/12RBQ(√(r/2))
2FSK频率 f1/f2|f₂−f₁|+2RBQ(√r)
2PSK相位 0/π2RBQ(√2r) 最优

r 为解调器输入信噪比。抗噪声性能：2PSK > 2FSK > 2ASK。

8.2 2PSK 的倒π问题与 2DPSK

2PSK 相干解调时本地载波相位跳变 π 会导致输出全错（"倒π"现象）。解决：差分相移键控 2DPSK —— 用相邻码元相位差携带信息，接收端差分译码。

8.3 多进制数字调制

MASK/ MPSK/ MQAM：每符号 log2M bit，频带利用率 η = log2M (bit/s/Hz)
  • QPSK：卫星、DVB-S 的经典调制，抗噪好
  • 8PSK：EDGE、卫星
  • 16QAM/64QAM/256QAM：幅度相位联合调制，效率高但对信噪比要求高（Wi-Fi、4G/5G、Cable）

8.4 各种调制误码率统一形式

MPSK: Ps ≈ 2Q(√(2k·rb)·sin(π/M))，k=log2M

第九章 QAM 与高性能调制

9.1 QAM 星座图

正交幅度调制：I/Q 两路独立的多电平 ASK 正交叠加。16QAM = 4×4 星座，每符号 4 bit。

调制bit/符号典型应用
QPSK2卫星、CDMA 导频
16QAM4Wi-Fi 802.11a/g
64QAM6Wi-Fi 5 / LTE
256QAM8Wi-Fi 6 / 5G
1024QAM10Wi-Fi 7

9.2 最小频移键控（MSK）与 GMSK

  • MSK：相位连续的 2FSK，调制指数 h=0.5，包络恒定、频谱紧凑
  • GMSK：MSK 前加高斯预调制滤波器，带外辐射更低 —— GSM 空口标准调制

9.3 星座图工程解读

⚠️ 工程口诀：星座点发散=噪声大；旋转=载波频偏；压缩=放大器非线性(AM/AM)；偏移=直流分量(IQ不平衡)。学会看星座图，是射频工程师的基本功。

第十章 信道编码（纠错码）

10.1 差错控制三种方式

  • 检错重发（ARQ）：TCP、HARQ —— 可靠但时延不定
  • 前向纠错（FEC）：实时性好 —— 主流方向
  • 混合纠错（HEC）：ARQ+FEC 结合

10.2 差错控制编码基本概念

纠错能力 t 位 ←→ 码距 d ≥ 2t+1；检错能力 e 位 ←→ d ≥ e+1

(n,k) 码：k 位信息 + r=n−k 位监督。编码效率 R = k/n。

10.3 线性分组码与汉明码

(7,4) 汉明码：4 位信息编 7 位码字，可纠正 1 位错。

# (7,4)汉明码监督方程
s1 = a6⊕a5⊕a4⊕a2
s2 = a6⊕a5⊕a3⊕a1
s3 = a6⊕a4⊕a3⊕a0
# 伴随式 s3s2s1 非0 → 由校正子表定位错误位

10.4 循环码与 CRC

g(x) 生成多项式整除码多项式 → 循环码；CRC 用于检错（以太网 FCS = CRC-32）

10.5 卷积码与维特比译码

  • 卷积码 (n,k,K)：记忆长度 K（约束长度），输出与当前及此前 K−1 组输入有关
  • 维特比算法：最大似然序列译码，网格图上找最小汉明距离路径 —— 深空通信、2G/3G 核心

10.6 现代信道编码

码特点应用
Turbo 码并行级联+迭代译码，逼近香农限3G/4G 上行
LDPC 码稀疏校验矩阵，长码性能优5G 数据、Wi-Fi 6、DVB-S2
Polar 码唯一被证明可达香农限的码5G 控制信道

第十一章 同步原理

11.1 载波同步

  • 直接法：平方环（2PSK→倍频提取 2fc→二分频）、科斯塔斯环（Costas Loop）
  • 插入导频法：发送端插入导频，接收端窄带滤波提取

11.2 位同步（码元同步）

  • 滤波法：延迟相乘产生时钟分量
  • 锁相法（Gardner 算法）：数字接收机通用

11.3 帧同步

利用巴克码（如 1110010，自相关旁瓣 ≤1）作帧头，通过相关运算确定帧边界。E1 帧同步码为 0011011。

11.4 网同步

主从同步（SDH 时钟树）、相互同步、GPS/北斗授时 —— 电信网络频率同步与相位同步（PTP/1588v2）。

第十二章 最佳接收与匹配滤波

12.1 匹配滤波器

h(t) = k·s(T−t)，在抽样时刻 t=T 输出最大 SNR：rmax = 2E/n0

匹配滤波器的冲激响应是信号波形的时间反转平移 —— 相关接收机的物理实现。

12.2 最佳接收机结构

接收信号 r(t) → 与每个可能波形 s₁(t)...sₘ(t) 做相关 → 取最大者作为判决
（等价于匹配滤波器组 + 抽样判决）

12.3 误码率统一比较

Pe = Q(√(Eb/n0)) —— 2PSK 相干（最优二进制）

Eb/n0（比特能量与噪声谱密度比）是数字通信最核心的参数，链路预算最终都归结为它。

12.4 链路预算实例

EIRP(dBW) = Pt(dBW) + Gt(dBi) − Lf(馈线)
Pr(dBm) = EIRP − Lfs(自由空间) − Lmisc + Gr
C/N₀ = EIRP + G/T − L - k(玻尔兹曼常数 dB)
自由空间损耗 Lfs = 92.45 + 20lg f(GHz) + 20lg d(km) dB

第十三章 OFDM 与现代通信技术

13.1 为什么需要 OFDM

宽带信号历经多径 → 频率选择性衰落 → 单载波均衡复杂。OFDM 将宽带信道切成大量正交窄带子载波，每个子载波只经历平坦衰落，均衡极简。

13.2 正交性与实现

子载波间隔 Δf = 1/Tsymbol（正交条件）；N 点 IFFT 并行调制 N 个子载波
发送：比特流 → 串并转换 → 星座映射(QAM) → IFFT → 加循环前缀CP → 并串 → DAC
接收：ADC → 去CP → FFT → 信道均衡(每子载波一个复数乘法) → 判决
  • 循环前缀 CP：复制尾部到头部（长于最大多径时延），将线性卷积变循环卷积，消除 ISI 与 ICI
  • 优点：频谱效率高、抗多径、易与 MIMO 结合
  • 缺点：高峰均比 PAPR（功放效率低）、对频偏/相位噪声敏感

13.3 OFDM 家族应用

系统技术
Wi-Fi (802.11a/ac/ax)OFDM / OFDMA
4G LTE下行 OFDMA、上行 SC-FDMA（低PAPR）
5G NRCP-OFDM + 灵活参数集（子载波间隔 15~240 kHz）
ADSL/VDSL、电力线DMT（离散多音）
数字广播 DAB/DVB-TCOFDM（编码OFDM）

13.4 扩频通信

  • 直扩 DS-SS：数据与伪随机码(PN)异或展宽频谱，处理增益 G = Bss/Bd —— CDMA、GPS
  • 跳频 FH-SS：载频按伪随机序列跳变 —— 蓝牙、军用抗干扰

第十四章 习题与思考

1.（计算）某信源含 8 个符号，概率分别为 1/2、1/4、1/8、1/16、1/32、1/64、1/64、1/64，求信源熵。

H = ΣP·log₂(1/P) = 1/2×1 + 1/4×2 + 1/8×3 + 1/16×4 + 1/32×5 + 3×(1/64×6)

= 0.5 + 0.5 + 0.375 + 0.25 + 0.15625 + 0.28125 = 2.0625 bit/符号

（小于 log₂8 = 3 bit，因为信源不等概存在冗余）

2.（计算）电话信道带宽 3.1 kHz，信噪比 30 dB，求信道容量；若要传 33.6 kbit/s 需多大信噪比？

30 dB → S/N = 1000。C = 3100×log₂(1001) ≈ 3100×9.97 ≈ 30.9 kbit/s

33.6 kbit/s 时：log₂(1+S/N) = 33600/3100 = 10.84 → S/N = 2^10.84 ≈ 1845 ≈ 32.7 dB

（56k Modem 采用的是非对称数字技术，已接近电话线极限）

3.（概念）为什么 2DPSK 能克服 2PSK 的"倒π"现象？

2DPSK 信息携带在相邻码元相位差中而非绝对相位。即使本地载波相位翻转 π，相邻码元的相位差不变，差分译码后信息仍正确，代价是误码会"成对"出现（约2倍误码扩散）。

4.（计算）某系统采用 16QAM，符号率 2 MBaud，求比特速率与滚降 α=0.5 时的占用带宽。

比特速率 = 2M × log₂16 = 8 Mbit/s

基带带宽 B = (1+α)×Rs/2 = 1.5×1M = 1.5 MHz，已调信号带宽（通带）= 3 MHz

频带利用率 = 8/3 ≈ 2.67 bit/s/Hz

5.（概念）OFDM 中循环前缀 CP 的作用是什么？CP 过长或过短各有何问题？

作用：①CP 长度 ≥ 最大多径时延时，消除符号间 ISI；②把线性卷积变循环卷积，使 FFT 后每子载波只受单一复数衰落（频率平坦），均衡简化为一个复数乘法。

CP 过短 → 残余 ISI/ICI；CP 过长 → 频谱与功率效率下降（开销比例 = TCP/(TCP+Tu)），5G 通过可配置 CP 长度折中。

6.（计算）(7,4) 汉明码的对偶距离是多少？能纠几位错？若收到码字 1000101，用监督方程判断是否有错。

dmin = 3，可纠 1 位错、检 2 位错。

代入监督方程计算校正子（按教材生成矩阵约定），若伴随式 ≠ 000 则有错并可由校正子表定位错误比特取反纠正。

7.（思考）FM 与 AM 广播音质差异巨大的物理本质是什么？

FM 通过大调频指数 mf 获得约 3mf2(mf+1) 的制度增益，即用带宽换信噪比（FM 带宽 200kHz vs AM 10kHz）；且限幅器可去除包络上的幅度噪声。两者共同使 FM 解调输出信噪比远高于 AM。

第十五章 MATLAB 仿真实验

实验一：AM 调制与解调

fm = 10; fc = 100; fs = 4000; t = 0:1/fs:0.5;
mt = cos(2*pi*fm*t);                       % 基带信号
s = (1 + 0.5*mt).*cos(2*pi*fc*t);          % AM 调制(调幅度0.5)
figure; subplot(311); plot(t,mt); title('调制信号');
subplot(312); plot(t,s);  title('AM已调波');
subplot(313); pwelch(s,[],[],[],fs); title('功率谱');

实验二：PCM 编解码（A律）

x = sin(2*pi*5*(0:255)/256);               % 抽样值
pcm = compand(x, 87.6, 1, 'a/compressor'); % A律压缩
q   = round(pcm*127)/127;                  % 均匀量化8bit
y   = compand(q, 87.6, 1, 'a/expander');   % A律扩张
snr = 10*log10(mean(x.^2)/mean((x-y).^2));
fprintf('量化信噪比 = %.1f dB\n', snr);

实验三：QPSK 调制与误码率曲线

N = 1e5; data = randi([0 1],N*2,1);
symbols = bi2de(reshape(data,2,[])','left-msb');      % 比特→符号
Map = exp(1j*pi/4*[0 2 3 1]);                         % QPSK星座
s = Map(symbols+1);
EbN0dB = 0:10;
for k = 1:length(EbN0dB)
  n = sqrt(0.5)*(randn(size(s))+1j*randn(size(s)));
  r = s + 10^(-EbN0dB(k)/20)*sqrt(2)*n;
  demod = argmin(abs(r(:,1)-Map(:)));                % 最近邻判决
  ber(k) = sum(demod-1 ~= symbols)/length(symbols);
end
semilogy(EbN0dB, ber, 'o-'); grid on;
hold on; semilogy(EbN0dB, 0.5*erfc(sqrt(10.^(EbN0dB/10)))); % 理论2PSK

实验四：OFDM 收发链路

N = 64; CP = 16; M = 16;                        % 64子载波,16CP,16QAM
bits = randi([0 1], N*log2(M), 1);
X = qammod(bits, M, 'InputType','bit');          % 星座映射
x = ifft(X, N);                                  % IFFT
xs = [x(end-CP+1:end); x];                       % 加循环前缀
% 信道: 3径衰落
h = [1 0.5*exp(-1j*pi/6) 0.3*exp(-1j*pi/3)];
r = filter(h,1,xs);
r = r(CP+1:end);                                 % 去CP
Y = fft(r, N);                                   % FFT
H = fft(h, N);                                   % 频域信道
Xeq = Y./H;                                      % 单抽头均衡
bitsRx = qamdemod(Xeq, M, 'OutputType','bit');
disp(['误比特率 = ', num2str(mean(bits~=bitsRx))]);

实验五：眼图观察

% 升余弦滤波后观察眼图
sps = 16; N = 2000;
b = rcosdesign(0.35, 8, sps, 'sqrt');
data = 2*randi([0 1],N,1)-1; dataU = upsample(data, sps)';
tx = filter(b,1,dataU);
eyediagram(tx(2000:end), 2*sps, sps);  % 每屏2个码元
