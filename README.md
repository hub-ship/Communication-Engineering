# 通信工程学习站

本科通信工程专业课程学习网站（纯静态 HTML，离线可用，无任何外部依赖）。

## 目录结构

```
通信工程/
├── index.html              # 主页（7门课程入口 + 学习路线 + 总览）
├── os-linux.html           # 操作系统与Linux管理（13章）
├── comm-principle.html     # 通信原理（15章，含MATLAB仿真）
├── signal-system.html      # 信号与系统（13章，含Python仿真）
├── c-programming.html      # C语言程序设计（14章）
├── mcu.html                # 单片机原理与应用（14章，51→STM32）
├── data-network.html       # 数据通信与网络技术（14章，含Socket/Wireshark）
├── mobile-comm.html        # 移动通信（13章，2G→6G）
├── css/styles.css          # 全站统一样式
├── js/main.js              # 返回顶部/导航高亮/代码块增强
├── assets/                 # 预留静态资源目录
└── _backup_删除的占位文件_20260830/   # 历史占位文件备份（可删）
```

## 使用方法

1. 双击 `index.html` 即可在浏览器打开主页；
2. 点击课程卡片或顶部导航进入任意课程；
3. 课程页左侧为章节目录，点击直达对应章节；
4. 习题答案点击题目折叠展开；代码块右上角标注语言。

## 内容特点

- 每门课程包含：章节正文、公式、表格对比、代码示例、习题（带答案）、实验指导、学习目标检查清单；
- 路线建议：C语言 → 信号与系统 → 通信原理 → 数据通信 → 单片机 → 移动通信 → 操作系统与Linux。

## 技术说明

- 纯 HTML/CSS/JS，无需服务器与构建工具，可离线访问或直接部署到任意静态托管（GitHub Pages / CloudBase 等）；
- 响应式布局，适配手机与桌面浏览器。
