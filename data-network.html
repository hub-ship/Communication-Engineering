第一章 数据通信基础

1.1 数据通信系统模型

源系统(源点+发送器) → 传输系统(信道) → 目的系统(接收器+终点)
五大部件 + 协议(通信双方共同遵守的规则)

1.2 基本术语

术语含义
码元一个数字脉冲（可携带 log₂M bit，M为进制）
波特率码元速率（Baud）
比特率信息速率（bit/s）= 波特率 × log₂M
带宽(模拟)Hz；带宽(数字)：bit/s —— 注意语境
时延发送+传播+处理+排队

1.3 时延计算（必考）

发送时延 = 分组长度/发送速率　　传播时延 = 距离/传播速度（约2×10⁸ m/s）
例: 1000字节分组, 100Mbps链路, 1000km光纤
发送时延 = 8000bit / 10⁸ bit/s = 80μs
传播时延 = 10⁶m / (2×10⁸m/s) = 5ms   → 传播占绝对主导!

1.4 交换方式

方式原理优缺点
电路交换先建立专用通路实时好、利用率低（电话）
报文交换整个报文存储转发时延大、需大缓存
分组交换切小组存储转发灵活高效、有排队时延（因特网）⭐

第二章 网络体系结构

2.1 OSI 七层模型

层次功能数据单元设备/协议
7 应用层为用户提供服务报文HTTP/FTP/DNS
6 表示层格式转换/加密压缩—JPEG/SSL
5 会话层建立管理会话—RPC
4 传输层端到端可靠传输段(Segment)TCP/UDP ⭐
3 网络层寻址与路由包(Packet)IP/ICMP/路由器 ⭐
2 数据链路层相邻节点成帧传输帧(Frame)以太网/PPP/交换机 ⭐
1 物理层比特传输比特(Bit)网线/光纤/中继器
💡 记忆口诀（物数网传会表应）：物联网淑惠试用 —— OSI 是理论模型，实际互联网采用 TCP/IP 四层（应用/传输/网际/网络接口）。

2.2 封装与解封装

发送方: 数据 → +TCP头(段) → +IP头(包) → +MAC头+FCS(帧) → 比特流
接收方: 逐层剥头,同层协议对话(逻辑直接通信,物理逐层传递)

第三章 物理层与传输媒介

3.1 导引型媒介

媒介距离带宽特点
双绞线(UTP)100m百MHz便宜,568B线序,水晶头
同轴电缆数百m高抗干扰强,视频/旧以太网
光纤(单模)几十km+THz级细芯激光,长途干线
光纤(多模)几百m~2km高粗芯LED,楼宇布线

3.2 无线媒介

  • 无线电：短波（天波反射）、微波（视线中继/卫星）
  • ISM 免许可频段：2.4GHz / 5GHz / 60GHz（Wi-Fi、蓝牙共用 2.4G）
  • 信道复用：FDM 频分 → OFDM 正交频分 → WDM 波分（光纤扩容神器）

3.3 常见物理层标准

10BASE-T  → 10Mbps 双绞线
100BASE-TX → 快速以太网(百兆)
1000BASE-T → 千兆(四对全双工)
10GBASE-SR → 万兆多模光纤
光纤接口: LC/SC/ST; 双绞线: RJ45

第四章 数据链路层与以太网

4.1 链路层的三个基本问题

  • 封装成帧：帧定界（MAC帧前导码、PPP标志0x7E）
  • 透明传输：字节填充（转义0x7D）/比特填充（连续5个1插0）
  • 差错检测：CRC 循环冗余校验（检错不纠错，错则丢弃）

4.2 CRC 校验计算（必考）

例: 数据 101110, 生成多项式 P=1101 (x³+x²+1)
步骤: 数据后补3个0 → 101110000 ÷ 1101 (模2除法,不借位)
     余数 = 011 → 发送帧 = 101110 011
接收方: 收到的整串除以P,余数为0 → 无错

4.3 以太网 MAC 帧

前导码(8B) | 目的MAC(6B) | 源MAC(6B) | 类型(2B) | 数据(46~1500B) | FCS(4B)
类型: 0x0800=IP  0x0806=ARP
MAC地址: 48位全球唯一, 前24位OUI厂商号
MTU = 1500字节(以太网)

4.4 CSMA/CD 与现代以太网

传统共享式以太网：载波监听多点接入/碰撞检测（半双工，退避算法）。现代交换式全双工以太网已无碰撞，CSMA/CD 仅具历史意义。

4.5 ARP 协议

作用: IP地址 → MAC地址(同一局域网内)
流程: 查缓存 → 无则广播ARP请求(目的MAC=FF:FF:FF:FF:FF:FF)
     → 目的主机单播应答 → 写入ARP表(缓存,有生存期)
# arp -a 可查看本机ARP表

第五章 交换机与 VLAN

5.1 交换机工作原理

  • 学习：收到帧 → 源MAC + 入端口 写入 MAC地址表
  • 转发：查目的MAC → 表中有则单播转发，无则向除入口外所有端口泛洪
  • 三层架构：接入层(接终端) → 汇聚层 → 核心层(高速转发)

5.2 VLAN 虚拟局域网

作用: 广播域隔离,安全+管理
实现: 802.1Q 在MAC帧插入4字节Tag(VLAN ID 1~4094)
Trunk口: 跨交换机承载多个VLAN; Access口: 属于单一VLAN
配置(H3C/华为风格):
[SWA] vlan 10
[SWA-vlan10] name teachers
[SWA] interface g0/0/1
[SWA-GigabitEthernet0/0/1] port link-type access
[SWA-GigabitEthernet0/0/1] port default vlan 10
[SWA] interface g0/0/24
[SWA-GigabitEthernet0/0/24] port link-type trunk
[SWA-GigabitEthernet0/0/24] port trunk permit vlan 10 20

5.3 链路聚合与生成树

  • 链路聚合(LACP)：多条物理线捆成一条逻辑链路，带宽叠加+冗余
  • 生成树协议 STP：阻塞冗余链路防广播风暴，故障时自动切换（RSTP秒级收敛）

第六章 网络层与 IP 协议

6.1 IPv4 首部关键字段

版本(4) 首部长度(4) 总长度(16) | 标识+标志+片偏移(分片用)
TTL(8,每过一个路由器-1,为0丢弃) | 协议(8: 1=ICMP 6=TCP 17=UDP)
首部校验和 | 源IP(32) | 目的IP(32)
首部20~60字节,路由器逐跳转发基于目的IP查路由表

6.2 IP 地址与子网划分（重中之重）

类别网络位/主机位默认掩码私有地址段
A类8/24255.0.0.010.0.0.0/8
B类16/16255.255.0.0172.16.0.0/12
C类24/8255.255.255.0192.168.0.0/16
可用主机数 = 2^(32−前缀长度) − 2（去掉网络地址与广播地址）

6.3 子网划分实例

例: 把 192.168.1.0/24 划分成4个子网
借用2位主机位 → 掩码 /26 → 255.255.255.192
子网1: 192.168.1.0/26   范围 .1~.62   广播 .63
子网2: 192.168.1.64/26  范围 .65~.126 广播 .127
子网3: 192.168.1.128/26 范围 .129~.190
子网4: 192.168.1.192/26 范围 .193~.254
每子网可用主机 = 2⁶-2 = 62台

6.4 特殊地址

地址含义
127.0.0.1环回（本机）
0.0.0.0任意/默认路由
255.255.255.255受限广播
169.254.x.xDHCP失败自动配置

6.5 NAT 与 IPv6

NAT: 私有地址 ↔ 公网地址转换(家用路由器标配), 缓解IPv4枯竭
IPv6: 128位地址(如 2001:db8::1), 无NAT、无广播、首部简化、
     SLAAC无状态自动配置。过渡技术: 双栈 / 隧道 / NAT64

第七章 路由原理与协议

7.1 路由器转发流程

收到IP包 → 减TTL → 查路由表(最长前缀匹配) → 下一跳+出接口
→ 重新封装链路层帧(改MAC) → 转发
无匹配则丢包并回 ICMP 不可达

7.2 静态路由 vs 动态路由

静态路由动态路由
配置手工协议自动学习
开销零协议开销CPU/带宽消耗
适应性差（故障需手改）自动收敛
场景小网络/末梢中大型网络

7.3 动态路由协议分类

协议类型算法适用
RIPIGP,距离矢量跳数(Bellman-Ford),最大15跳小型(教学)
OSPFIGP,链路状态Dijkstra SPF,开销=带宽中大企业/运营商 ⭐
BGPEGP,路径矢量策略路由(AS间)互联网骨干 ⭐

7.4 默认网关与路由表读法

# ip route 典型输出解读

192.168.1.0/24 dev eth0 proto kernel scope link src 192.168.1.100

第八章 传输层 TCP / UDP

8.1 端口号与套接字

端口(16位): 0~65535 | 知名端口0~1023 | 注册端口1024~49151
FTP 21 / SSH 22 / HTTP 80 / HTTPS 443 / DNS 53 / DHCP 67/68
套接字Socket = (IP, Port) 唯一标识一个通信端点

8.2 UDP 特点

  • 无连接、尽力而为、首部仅8字节、支持一对多
  • 应用层自己做可靠性的场景：DNS、DHCP、视频直播、RTP语音、游戏

8.3 TCP 特点（核心考点）

  • 面向连接（三次握手 / 四次挥手）
  • 可靠传输：确认应答、超时重传(RTO自适应)、校验
  • 流量控制：滑动窗口（接收方通告 rwnd）
  • 拥塞控制：慢启动、拥塞避免、快重传、快恢复（AIMD）

8.4 三次握手与四次挥手

建立连接(三次握手):
客户端 → SYN(seq=x)           → 服务器
客户端 ← SYN+ACK(seq=y,ack=x+1) ← 服务器
客户端 → ACK(ack=y+1)         → 服务器
(防失效连接请求/确认双方收发能力)

释放连接(四次挥手):
主动方 → FIN → 被动方
主动方 ← ACK ← 被动方      (被动方处理剩余数据)
主动方 ← FIN ← 被动方
主动方 → ACK → 被动方      (主动方TIME_WAIT等待2MSL)

8.5 TCP 拥塞控制四阶段

慢启动: cwnd从1MSS指数增长到门限ssthresh
拥塞避免: cwnd线性+1 MSS/RTT
快重传: 连续3个重复ACK → 立即重传(不等超时)
快恢复: ssthresh=cwnd/2, cwnd=ssthresh(新算法如CUBIC/BBR)

第十一章 Socket 编程

11.1 Socket 编程模型

TCP服务器: socket → bind → listen → accept → recv/send → close
TCP客户端: socket → connect → send/recv → close
UDP:       socket → bind(可选) → sendto/recvfrom → close

11.2 TCP 服务器完整示例（Linux C）

#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>

int main(void)
{
    int srv = socket(AF_INET, SOCK_STREAM, 0);

    struct sockaddr_in addr;
    memset(&addr, 0, sizeof(addr));
    addr.sin_family      = AF_INET;
    addr.sin_port        = htons(8888);            /* 主机序→网络序! */
    addr.sin_addr.s_addr = htonl(INADDR_ANY);      /* 监听所有网卡 */

    bind(srv, (struct sockaddr *)&addr, sizeof(addr));
    listen(srv, 5);                                /* backlog队列 */

    printf("listening on 8888...\n");
    while (1) {
        struct sockaddr_in cli;
        socklen_t len = sizeof(cli);
        int conn = accept(srv, (struct sockaddr *)&cli, &len);
        printf("client: %s:%d\n",
               inet_ntoa(cli.sin_addr), ntohs(cli.sin_port));

        char buf[1024];
        int n = recv(conn, buf, sizeof(buf)-1, 0);
        buf[n] = 0;
        send(conn, buf, n, 0);                     /* 回显服务器echo */
        close(conn);
    }
}

11.3 TCP 客户端

int fd = socket(AF_INET, SOCK_STREAM, 0);
struct sockaddr_in srv;
srv.sin_family = AF_INET;
srv.sin_port   = htons(8888);
inet_pton(AF_INET, "127.0.0.1", &srv.sin_addr);   /* 点分串→二进制 */

connect(fd, (struct sockaddr *)&srv, sizeof(srv));
send(fd, "hello", 5, 0);
char buf[1024];
int n = recv(fd, buf, sizeof(buf)-1, 0);
buf[n] = 0;
printf("echo: %s\n", buf);
close(fd);

第十三章 习题与思考

1.（计算）CRC：数据 101010，生成多项式 1101，求发送码字。

数据后补3个0：101010000，模2除以1101：
101010000 ÷ 1101 → 余数 = 110（过程：异或不借位长除）
发送码字 = 101010110。接收方整除校验，余数非0即传输出错。

2.（计算）主机 IP 172.16.130.100，掩码 255.255.128.0，求网络地址与广播地址。

掩码 /17。130 = 10000010，取最高1位与网络位对齐：
网络地址 = 172.16.128.0/17，广播地址 = 172.16.255.255，
可用主机 = 2¹⁵ − 2 = 32766 台。

3.（概念）为什么 TCP 建立连接是三次握手而释放连接要四次挥手？

三次：本质是"双方各发一次 SYN 并确认对方的 SYN"，2×2=4 个动作中服务器可把 SYN+ACK 合并，故3次已够。
四次：收到 FIN 只代表对方不再发送，我方可能还有数据要发，ACK 与 FIN 不能合并，必须分开。

4.（思考）发送 1MB 文件走 1Gbps 链路（RTT 忽略），与走卫星链路（RTT 500ms，停等协议），各需多久？说明什么问题？

① 1MB/1Gbps ≈ 8ms（带宽主导）。
② 停等协议每 RTT 发一窗：1MB/1460B ≈ 7197 个包 × 500ms ≈ 3600s！带宽时延积 BDP = 10⁹×0.25s = 250Mb，停等窗口远小于 BDP，信道利用率极低。
结论：高时延带宽积网络必须用滑动窗口/大窗口+选择性重传，这正是 TCP 滑动窗口存在的意义。

5.（读代码）指出这段 Socket 代码的两处错误。 
struct sockaddr_in addr;
addr.sin_family = AF_INET;
addr.sin_port   = 8888;                 /* ①没 htons,端口字节序错 */
bind(fd, (struct sockaddr*)&addr, sizeof(addr));
addr.sin_addr.s_addr = inet_addr("192.168.1.1");  /* ②bind之后才设置地址,无效 */

修正：sin_port = htons(8888)；所有字段应在 bind/connect 前配置完成。

6.（设计）宿舍6台电脑要隔离成2个独立网络，说明所需设备与配置思路。

一台二层交换机（支持VLAN）即可：端口1-3划分 VLAN10、端口4-6划分 VLAN20，两VLAN广播域隔离无法互访。若需互通，再上三层交换机配 SVI 网关（VLANif10/VLANif20）做 VLAN 间路由，可用 ACL 控制访问策略。

7.（综合）网页打不开，给出你的分层排查思路（自底向上）。

①物理/链路：ipconfig 看是否169.254（DHCP失败）→ 检查网线/交换机口；
②内网连通：ping 网关 → 不通查ARP/交换机；
③外网连通：ping 8.8.8.8 → 通则DNS问题（nslookup验证），不通查路由/NAT；
④传输/应用：telnet 域名 443 测端口 → Wireshark 抓包看是 DNS 卡住还是 TCP 重传丢包。
分层定位，逐层缩小范围。

第十四章 组网综合实验

实验拓扑（eNSP / Packet Tracer）

PC1 ──┐                          ┌── PC3 (VLAN20)
      ├── [SW1] ── Trunk ── [SW2]┤
PC2 ──┘   (VLAN10/20)            └── PC4 (VLAN20)
   SW1上联口 → [AR1路由器] → 模拟外网 (Loopback 8.8.8.8)

配置清单（华为命令）

# 1.交换机VLAN与端口
[SW1] vlan batch 10 20
[SW1] int e0/0/1 ; port link-type access ; port default vlan 10
[SW1] int e0/0/24 ; port link-type trunk ; port trunk permit vlan 10 20

# 2.路由器单臂路由实现VLAN间通信
[AR1] int g0/0/0.10
[AR1-GigabitEthernet0/0/0.10] dot1q termination vid 10
[AR1-GigabitEthernet0/0/0.10] ip address 192.168.10.1 24
[AR1-GigabitEthernet0/0/0.10] arp broadcast enable
# (或SW做三层: interface Vlanif10 + ip address)

# 3.静态路由/默认路由
[AR1] ip route-static 0.0.0.0 0 200.1.1.2     # 去外网
[SW1] ip route-static 0.0.0.0 0 192.168.10.1  # 回程路由

# 4.PC配置: IP+掩码+网关(指向对应VLANif/Dot1q地址)
# 5.验证: PC1 ping PC4(跨VLAN) / PC1 ping 8.8.8.8(跨网段)

进阶：DHCP + NAT 让全网自动上网

[AR1] dhcp enable
[AR1] int g0/0/0.10 ; dhcp select interface    # 接口地址池自动分配
[AR1] acl 2000 ; rule permit source 192.168.0.0 0.0.255.255
[AR1] int g0/0/1 ; nat outbound 2000          # 内网共享公网口上网
